Abyss Theme

Theme by Om Gupta (AumGupta), MIT licensed.

Applies to compatible server-hosted Jellyfin Web with Dark selected. Native clients, the separate dashboard and Spotlight are not covered.

Loading status…

Off by default. When enabled, checks upstream main on startup and every 24 hours. Requires access to api.github.com and raw.githubusercontent.com. All CSS files and the MIT license are downloaded at the same revision. A failed check retains the active theme.

Optional plugin adaptations

Enable only for plugins you use. These options add Abyss CSS; they do not install or configure those plugins. Upstream adaptations are version specific and may lag newer plugin versions. Compatibility has not been verified with actual installations of these two plugins.

Bundled override targets Jellyfin Enhanced 11.3.0.0. Updates may change the target version; check the upstream guide.

Bundled override targets Media Bar Enhanced 1.9.0.0. Updates may change the target version; check the upstream guide.

Reload open Web clients after any change. If cached CSS persists, restart Jellyfin and hard refresh. CSS validation does not guarantee visual compatibility.

Recovery and reset

Return to the previous downloaded revision, or the bundled revision if none exists. Rollback also disables automatic updates so the rejected revision is not immediately applied again.

Reset restores the bundled theme and switches off both adaptations and automatic updates.
